# よみがえり窓 (YomigaeriMado)

Ubuntu を再インストールしたあとに、前のパソコンに入れていたアプリをまとめて入れ直すためのソフトです。

## できること

- 今のパソコンに入っているアプリ（Snap / apt / Flatpak）をリスト（JSON ファイル）に書き出す
- 再インストール後にリストを開き、チェックを入れたアプリをまとめてインストールする（パスワードは最初の1回だけ）
- GitHub のリリースで配布されている DEB アプリは、最新版を自動でダウンロードしてインストールする
- 失敗したものだけをやり直す
- **定番カタログ**：まだ入っていない定番ソフト（日本語入力・フォント・コーデック・開発ツールなど約40個）を選んで入れる。「日本語環境」「動画・音楽」などの目的別セットでまとめて選べる。チェックしたものを自分のセットとして保存することもできる
- **自動書き出し**：毎日 / 毎週、決めたフォルダ（クラウドや USB）にリストを自動で保存する
- **これ1つで復元**：リストと一緒に復元スクリプト `よみがえり.sh` を作る。まっさらな Ubuntu で `bash よみがえり.sh` と実行すると、よみがえり窓を入れてリストを開く
- **インストール後の設定**：Mozc を入れたら入力ソースに追加する、Flatpak を入れたら Flathub を登録する、など

## インストール

[Releases](https://github.com/kenjiiida-commits/YomigaeriMado/releases) から `yomigaeri-mado_*_all.deb` をダウンロードして、次のコマンドを実行します。

```
sudo apt install ./yomigaeri-mado_0.3.0_all.deb
```

インストールすると、アプリメニューに「よみがえり窓」が表示されます。

## 使い方

1. **再インストールの前に**「① 今のアプリを書き出す」を押し、リストを USB メモリやクラウドに保存します。
2. 「DEBファイル」と表示された行は、「GitHub の場所を設定…」で配布元（例: `owner/repo`）を入れて「リストを保存」すると、自動で入れられるようになります。
3. **再インストールの後で**、リストと同じフォルダにある `よみがえり.sh` を `bash よみがえり.sh` で実行します（よみがえり窓が入って、リストが開きます）。すでに入っている場合は「② リストを開く」でも開けます。まだ入っていないアプリには、最初からチェックが入っています。
4. 「③ 選んだものをまとめてインストール」を押します。

## コマンドでの使い方

```
yomigaeri-mado --export フォルダ    # 画面を出さずに書き出す
yomigaeri-mado --open リスト.json   # リストを開いて起動
```

## 注意

- 「動画・音楽コーデック」（ubuntu-restricted-extras）は、Microsoft フォントの利用規約に同意したものとしてインストールします。

- PPA など追加の入手先が必要なソフトは失敗になります。
- GitHub 以外のサイトから入れた DEB は、自動では入れられません。

## 動作環境

Ubuntu 26.04 LTS（Python 3 + PySide6）

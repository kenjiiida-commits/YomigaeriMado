# よみがえり窓 (YomigaeriMado)

Ubuntu を再インストールしたあとに、前のパソコンに入れていたアプリをまとめて入れ直すためのソフトです。

## できること

- 今のパソコンに入っているアプリ（Snap / apt / Flatpak）をリスト（JSON ファイル）に書き出す
- 再インストール後にリストを開き、チェックを入れたアプリをまとめてインストールする（パスワードは最初の1回だけ）
- GitHub のリリースで配布されている DEB アプリは、最新版を自動でダウンロードしてインストールする
- 失敗したものだけをやり直す

## インストール

[Releases](https://github.com/kenjiiida-commits/YomigaeriMado/releases) から `yomigaeri-mado_*_all.deb` をダウンロードして、次のコマンドを実行します。

```
sudo apt install ./yomigaeri-mado_0.2.1_all.deb
```

インストールすると、アプリメニューに「よみがえり窓」が表示されます。

## 使い方

1. **再インストールの前に**「① 今のアプリを書き出す」を押し、リストを USB メモリやクラウドに保存します。
2. 「DEBファイル」と表示された行は、「GitHub の場所を設定…」で配布元（例: `owner/repo`）を入れて「リストを保存」すると、自動で入れられるようになります。
3. **再インストールの後で**「② リストを開く」を押します。まだ入っていないアプリには、最初からチェックが入っています。
4. 「③ 選んだものをまとめてインストール」を押します。

## 注意

- PPA など追加の入手先が必要なソフトは失敗になります。
- GitHub 以外のサイトから入れた DEB は、自動では入れられません。

## 動作環境

Ubuntu 26.04 LTS（Python 3 + PySide6）
